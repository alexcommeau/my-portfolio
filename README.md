# Portfolio de Alex Commeau

Portfolio personnel présentant mes projets et compétences en développement web et intelligence artificielle.

## À propos

Développeur passionné par les technologies de l'IA générative, je crée des applications web innovantes qui combinent l'expérience utilisateur et les dernières avancées en intelligence artificielle.

## Fonctionnalités

- Design moderne avec effet de flou sur l'arrière-plan
- Navigation fluide entre les sections
- Responsive design pour tous les appareils
- Animations et transitions fluides

## Développement

```bash
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.
